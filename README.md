# 地緣風險理財課｜財務韌性生存模擬（MVP）

5–7 人讀書會用的手機＋大螢幕遊戲。玩家用手機加入，主持人用電腦推進五幕並投影匿名統計。
沒有棋盤：**五幕本身就是遊戲地圖**。

## 快速試玩（不需要 Firebase）

```bash
npm install
npm run dev
```

打開 http://localhost:3000：

1. 在一個分頁按「建立房間」→ 這是主持人大螢幕。
2. 開 2–3 個新分頁，輸入房間碼與暱稱加入 → 每個分頁是一位玩家。

未設定 Firebase 時會自動進入**本機示範模式**，房間只在同一個瀏覽器的分頁之間同步，適合彩排與測試。

## 正式使用（Firebase＋Vercel）

1. 在 Firebase Console 建立專案：
   - Authentication → 啟用 **Anonymous**
   - Firestore Database → 建立資料庫
   - 專案設定 → 新增 Web App，取得設定值
2. 部署安全規則：`npx firebase-tools deploy --only firestore:rules`（使用本目錄的 `firestore.rules`）
3. 把 `.env.example` 的四個變數填到 `.env.local`（本機）或 Vercel 的 Environment Variables。
4. 部署到 Vercel：匯入此專案即可，不需額外設定。

## 流程

| 玩家手機 | 主持人大螢幕 |
|---|---|
| 首頁 → 加入房間 → 等候室 | 建立房間 → QR Code 等候室 |
| 角色揭曉 | 開始（隨機分配 7 角色） |
| 和平配置（20 點調整權） | 推進幕次、查看提交狀態 |
| 警訊決策（擇一）＋第一次骰子 | 公布匿名統計 |
| 金融冰封：資產翻牌 | 擠兌效應判定、知識揭曉 |
| 生存期 | 生存期分布 |
| 擲骰支線 Month 1–3 | 逐月推進、缺口統計 |
| 復原：世界情境＋第 4–6 個月結算 | 抽出世界情境 |
| 韌性報告（五維雷達＋結局） | 全場結局分布 |
| 個人行動（私人壓力測試、行動卡下載） | — |

主持人隨時可以：暫停討論（大螢幕顯示討論題）、插入迷思快問快答（匿名 YES/NO 投票）。

## 隱私

- 玩家只能讀寫自己的資料；主持人畫面只顯示彙總，提交狀態只顯示「是否完成」。
- 私人壓力測試與行動卡**只在手機記憶體中計算**，不寫入 Firestore、也不寫入瀏覽器儲存。

## 程式結構

- `lib/game.ts`：遊戲數學層（角色、資產、事件、五維計分、結局）。純函式，玩家端、主持人端、模擬腳本共用。
- `lib/backend.ts`：後端抽象（Firebase／本機示範模式）。Firestore 只存「決策」，結果一律由 `runGame()` 即時計算。
- `app/play/[code]`：玩家手機畫面。`app/host/[code]`：主持人大螢幕。
- `scripts/simulate.ts`：平衡測試，`npm run sim`。
- 數值說明見 `DESIGN.md`。
